# OXYRA — Oxygen Intelligence

A static, responsive concept dashboard for oxygen inventory visibility and modeled demand forecasting.

## Files
- `index.html` — dashboard structure and metadata
- `style.css` — responsive visual design
- `script.js` — fictional sample data, search, filters, alerts, forecast chart, and detail dialog
- `favicon.svg` — OXYRA browser icon

## Run locally
Open `index.html` in a browser. Google Fonts needs an internet connection; the dashboard itself has no backend dependency.

## Publish with GitHub Pages
1. Upload all five project files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your main branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important
This is a product-design demo. All hospital names and values are fictional. It is not connected to hospital systems and must not be used for real clinical decisions, emergency response, or operational oxygen-supply planning.
