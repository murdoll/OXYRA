Как интерпретировать отчёт

Отчёт отражает только записи, доступные текущему пользователю. Если Supabase не подключён, выгрузка содержит только локальные записи этого браузера.

Перед передачей отчёта убедитесь, что в нём нет персональных или конфиденциальных данных, не предназначенных получателю.

Подключение и настройки

Настройте Supabase и поставщика картографических тайлов.

Безопасность: вставляйте только Project URL и публичный publishable/anon-ключ Supabase. Никогда не вставляйте service_role или secret key в HTML-файл. Доступ к данным должен ограничиваться RLS-политиками.

Подключение Supabase

Подключение использует REST API. Настройки хранятся локально в браузере, не в исходном HTML.

Не подключено

Ожидаемые таблицы: facilities, inventory_readings, deliveries, regions, data_sources, facility_memberships. Названия и поля должны совпадать с реальной схемой. Если запрос отклонён, сайт покажет ошибку, а не выдумает данные.

Реальная карта

Leaflet отображает тайлы выбранного поставщика. Вариант по умолчанию — EvaMaps.

Если тайлы EvaMaps не загружаются в вашей сети, выберите поставщика, доступного в вашем регионе, и используйте его официальный URL и условия. Для некоторых поставщиков необходим API-ключ. Доступность внешних карт не может быть гарантирована самим HTML.

Локальные данные

Локальные записи находятся только в этом браузере. Это не замена резервному копированию серверной базы.
